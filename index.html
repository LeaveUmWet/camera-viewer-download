Live View Wall
Windows beta

Single-camera live view in this beta.

A Windows viewer for property managers and contractors. This beta shows one Reolink camera or NVR channel live on your PC. A multi-camera wall is coming.

Download for Windows (beta) View release notes

Free local beta. No subscription. Windows 10 or 11, 64-bit. Installer is about 66 MB.

Front gate

Built as a desktop app for Windows, not a cloud camera service. When you connect by local IP or RTSP, video stays on your network. If you connect by Reolink UID and leave server assistance on, video and login traffic may pass through Reolink’s servers.

What this beta does

Reolink, first

Connect a camera or NVR by local IP and RTSP, or by Reolink UID. Test the connection, then watch a live tile on one screen.

Made for job sites

Aimed at property managers and contractors who need a simple live view, saved logins, and a Windows installer — not another browser tab. This beta is one camera; a multi-camera wall is coming.

Local, no monthly fee

The app runs on your PC. Camera passwords stay on that computer. There is no cloud subscription for the viewer itself.

Camera support

This beta is Reolink-only. Other brands are planned, and some cloud-only brands will not be supported.

Reolink — in this beta ONVIF (generic / no-name IP cameras) — planned Hikvision — planned Dahua — planned Amcrest — planned Annke — planned Axis — planned Uniview — planned Foscam — planned Tapo — planned Lorex — planned Nest — not supported Ring — not supported Arlo — not supported Blink — not supported Kasa — not supported SimpliSafe — not supported

Brand presets and ONVIF auto-discovery are on the roadmap. UniFi Protect, EZVIZ, and some Eufy, Wyze, Swann, and Zosi models may come later. This app does not claim to work with Nest or Ring.

Meet Ara

Ara is the setup assistant. When it is available in the app, it will speak this fixed intro before any questions begin:

  1. “Welcome to your ultimate camera viewer. My name is Ara. I'm here to help you set this up today.”
  2. “Would you like to have this as a voice conversation or a typing?”
  3. “Let's get your system set up today.”
  4. “Just so you know, I'm an AI assistant. Double-check any settings before you apply them.”

Ara is an AI assistant, not a person. Its answers can be wrong, so you should verify any settings before you apply them.

Not in this Windows beta (v0.1.0). The current installer opens a password setup and sign-in screen, then a camera form. Ara’s greeting, the voice-or-typing choice, and setup Q&A are planned and are not in the build dated October 24, 2026.

System requirements

Windows 10 or 11

64-bit PC. The installer is named Reolink.Live.View.Wall_0.1.0_x64-setup.exe.

WebView2

The app uses Microsoft Edge WebView2, which is already on most Windows 10/11 PCs. If it is missing, the installer can download it.

Your cameras’ network

This PC needs to reach the camera or NVR (same LAN, or a path the camera already uses). No account on this website is required to download.

If Windows says the app is unrecognized

This beta is not yet signed with a paid code-signing certificate, so Microsoft Defender SmartScreen may show a blue box:

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting. Running this app might put your PC at risk.

Click More info, check that the file is the Live View Wall installer you just downloaded, then click Run anyway. Click Don't run if the file name looks wrong. This warning is expected for a new, unsigned app. It does not mean the file failed a virus scan.
