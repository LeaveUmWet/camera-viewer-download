Why this is incomplete. The private repo LeaveUmWet/Reolink currently contains design documents only (README, docs/, a phase-1 prompt). There is **no package-lock.json, pnpm-lock.yaml, yarn.lock, or Cargo.lock** to inventory. Do not ship an About screen that pretends this list is exhaustive.

Before the first public installer, generate the real list from the build that will actually ship:

  • JavaScript / Node: npx license-checker --production --csv (or license-checker-rseidelsohn) against the lockfile, and keep the output in this folder.

  • Sidecars (FFmpeg, go2rtc, whisper.cpp, Piper, and any model or voice files): list each binary, its exact version, the license of that build, and where source is offered.

Until that inventory exists, treat every row as “planned or likely,” not “confirmed bundled.”

Tauri

  • Upstream: github.com/tauri-apps/tauri
  • License: dual MIT OR Apache-2.0 (project license files).
  • Notice must appear: NOTICE file (both license texts or a clear dual-license statement, plus copyright), About screen.
  • Notes: Run cargo-about so Tauri’s own Rust dependencies (hundreds of crates) are listed. Apache-2.0 crates also require preservation of NOTICE files from those crates.

Microsoft Edge WebView2 Runtime

  • Docs: Distribute your app and the WebView2 Runtime
  • License: Microsoft software license terms for the WebView2 Runtime and SDK (not an open-source license). A production WebView2 app must use the WebView2 Runtime, not the Microsoft Edge Stable browser, as the backing web platform.
  • Redistribution (practical rule): The usual path is the Evergreen Runtime: detect whether it is already installed (it is present on most Windows 10/11 PCs) and, if not, run Microsoft’s official bootstrapper or offline installer. Do not treat the Runtime as something you rebrand or redistribute as a standalone product. The Fixed Version Runtime, if used, has stricter packaging rules (files you must ship, no running from a UNC path, and you must service it yourself).
  • Notice must appear: About screen (“This app uses the Microsoft Edge WebView2 Runtime”) and a link to Microsoft’s terms. The installer should also present or link to Microsoft’s terms if it installs the Runtime.
  • Notes: Confirm Evergreen vs Fixed Version in the shipping installer.

FFmpeg (if bundled as a Tauri sidecar)

  • Upstream / legal page: ffmpeg.org/legal.html
  • Default license: LGPL 2.1 or later. Optional parts are GPL 2 or later; if those parts are enabled, GPL applies to that FFmpeg build. FFmpeg is not offered under a paid proprietary license.
  • Notice must appear: - About box: “This software uses libraries from the FFmpeg project under the LGPLv2.1” (only if that is the actual build license). - Every website page that offers the download, per FFmpeg’s checklist: “This software uses code of FFmpeg licensed under the LGPLv2.1 and its source can be downloaded here” plus a working source link. - EULA: we do not own FFmpeg; limited reverse-engineering right to relink LGPL libraries; spell FFmpeg correctly.
  • Compliance work before shipping a sidecar: 1. Build or obtain an FFmpeg binary compiled without --enable-gpl and without --enable-nonfree, unless you are prepared to license the entire app under the GPL (almost certainly not the intent). 2. Do not link in GPL libraries such as libx264 / libx265. 3. Prefer dynamic linking (DLLs) so the user can relink. 4. Ship or host the exact corresponding FFmpeg source, configure line, and any patches, alongside the installer. 5. Do not rename avcodec.dll and similar to obfuscated names. 6. Audit filters used by the product. The phase-1 prompt mentions drawtext and v360. Upstream comments treat drawtext as usable in an LGPL build, but you must confirm the actual binary. If a required filter forces --enable-gpl, change the feature or get legal advice — do not silently ship a GPL FFmpeg inside a proprietary exe.
  • Patents. FFmpeg’s legal page warns that commercial use of patented codecs (including H.264 / MPEG-related technology) can attract licensing claims (for example from MPEG LA). This is a lawyer and insurance item for paid sales, not something a NOTICE file solves.
  • Trademark. FFmpeg is a trademark of Fabrice Bellard.

Ollama (not bundled in the Windows exe)

  • Notice must appear: About / notices, even though the viewer exe is not supposed to ship Ollama. The operator (and later, any customer who hosts a local model) installs Ollama separately.
  • Notes: Ollama’s MIT license does not replace the license of the model you pull (Llama 3.2 has its own terms).

Llama 3.2 (model weights; not distributed inside the exe)

  • License: Llama 3.2 Community License, release date 25 September 2024.
  • Acceptable Use Policy (incorporated into the license): llama.com/llama3_2/use-policy. Use of the materials must follow the AUP even when you do not redistribute weights. The AUP notably prohibits representing that outputs are human-generated, and requires disclosing known dangers of the AI system — which is one reason Ara’s intro disclosure and “may be wrong” note exist.
  • “Built with Llama” attribution. Section 1.b.i requires that if you “distribute or make available the Llama Materials (or any derivative works thereof), or a product or service (including another AI model) that contains any of them,” you must (A) provide a copy of the Agreement with those materials and (B) prominently display “Built with Llama” on a related website, UI, blog post, about page, or product documentation. Section 1.b.iii also requires a Notice file attribution if you distribute copies of the materials: “Llama 3.2 is licensed under the Llama 3.2 Community License, Copyright © Meta Platforms, Inc. All Rights Reserved.”
  • Judgment on whether attribution applies when weights are not in the installer. The Windows exe does not ship the weights. Ara still makes a product or service available that uses Llama 3.2 when the assistant is turned on and talks to Ollama on G-Tech (or on a later host). The conservative reading is that “Built with Llama” should appear on the About screen, the notices page, and (if Ara is advertised) the landing page, and that a copy of the Community License and AUP should be linked there. This is cheap and avoids a close call. If Ara is disabled and no Llama host is used, the About screen can still mention the optional assistant. Meta’s 700-million-MAU additional terms are not a practical concern at this scale.
  • Do not fine-tune or rename a derivative model without also following the “Llama” naming rule in Section 1.b.i.

whisper.cpp (if used for speech-to-text)

  • License: MIT (verified from the project LICENSE on 24 November 2026). Copyright (c) 2023–2026 The ggml authors.

Piper or other text-to-speech (if used)

  • Older engine: github.com/rhasspy/piper was MIT-licensed and is archived.
  • Successor: github.com/OHF-Voice/piper1-gpl is GPL-3.0-or-later. Bundling that successor in a proprietary Tauri app would raise a serious copyleft problem.
  • Voices: each voice has its own license, usually documented in that voice’s MODEL_CARD. Do not assume the engine license covers the voice.
  • Recommendation: if voice is shipped, use an engine and voice whose licenses are compatible with a closed-source app (for example the archived MIT Piper, or another MIT/Apache engine), record the exact versions, and include each voice’s license in this file. Do not bundle piper1-gpl without a lawyer’s blessing or a decision to GPL the app. Alternative engines mentioned in the project plan (for example VoiceStudio) must be checked the same way before use.
