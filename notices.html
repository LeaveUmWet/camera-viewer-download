Hosted Gemma 4 / Gemini API (not redistributed in the exe)

Ara (when a build includes it) calls Google’s hosted model gemma-4-26b-a4b-it through the Gemini API, via a Cloudflare Worker that holds the API key. The Windows installer does not ship Gemma weights, and Contemporary Innovations, LLC does not redistribute a copy of the model.

What governs API use (this is the live path). Use of the Gemini API is governed by the Gemini API Additional Terms of Service (effective 23 March 2026) and the Google APIs Terms of Service, including Google’s use restrictions for that API. Those service terms — not a weight-redistribution license — are what apply when the app calls Google’s hosted Gemma 4. The Terms of Use should require users not to use Ara in violation of those terms. The Privacy Policy must describe Google’s data-use rules for the live billing tier (unpaid vs Paid Services).

Gemma 4 weight license, if you later distribute or self-host weights. Official Gemma docs state that Gemma 4 is licensed under the Apache License 2.0. Sources: Gemma 4 model card, Apache License 2.0 text on gemma.ai. Apache 2.0’s redistribution conditions (license copy, modification notices, NOTICE file retention, and the standard attribution appendix) apply when you distribute copies of the Work or Derivative Works. Calling a hosted API, without shipping the weights, is not a typical Apache “redistribution” of the model. If you later bundle, fine-tune, or self-host Gemma 4 weights, follow Apache 2.0, including a NOTICE file.

Gemma Terms of Use and Prohibited Use Policy — do they apply here? The Gemma Terms of Use (last modified 1 April 2026) say, at the top: the terms on that page apply to the models listed in its Appendix, and “For Gemma 4 terms, see the Gemma 4 license.” The Appendix lists Gemma 1, 1.1, 2, 3, 3n, and various variants — not Gemma 4. Those older terms define a hosted API as “Distribution,” require you to pass through Section 3.2 use restrictions (the Gemma Prohibited Use Policy) as an enforceable provision, and require a “Notice” text file only for distributions other than through a Hosted Service.

Judgment: for the current design (hosted Gemma 4 via the Gemini API, no weight redistribution), do not treat the Gemma 1–3n Terms of Use pass-through, or a “Gemma is provided under the Gemma Terms of Use” NOTICE file, as a mandatory notice for this service. Practical notices for this path:

  • In the About screen and this file, state that Ara uses Google’s hosted Gemma 4 (gemma-4-26b-a4b-it) through the Gemini API.
  • Link the Gemini API Additional Terms (and Google APIs Terms).
  • Require users, in the product Terms of Use, to comply with those Google terms.
  • Optionally link the Apache 2.0 Gemma 4 license for completeness, without claiming you are redistributing the weights.
  • If the model is ever switched to a pre-Gemma-4 Gemma, or if weights are shipped or self-hosted, re-read the Gemma Terms of Use and (for Gemma 4 weights) Apache 2.0, and update this file.

Google’s trademarks: do not use Google or Gemma marks in a way that suggests endorsement. See the Gemini / Google brand rules and Apache 2.0 trademark language.

Piper or other text-to-speech (if used later)

  • Older engine: github.com/rhasspy/piper was MIT-licensed and is archived.
